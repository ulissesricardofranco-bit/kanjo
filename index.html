Parâmetros de cálculo

A taxa de referência converte o custo final (¥) em reais para o controle de vendas. Ex.: 0,032 = R$ 0,032 por iene (≈ ¥31,25 por real).

Contas de acesso

Usuários: ulisses (comprador, acesso total) e samuel (vendedor, sem a área de vendas). As contas ficam no Supabase — o mesmo login funciona em qualquer computador ou celular.

Se o samuel esquecer a senha dele, redefina no painel do Supabase (Authentication → Users → samuel@kanjo.local → Send password recovery / Update password) — ou peça ao Claude para redefinir.

Backup dos dados

Os dados ficam no banco online (Supabase) e são os mesmos para todos que acessam. O backup em JSON é uma cópia de segurança extra; a importação regrava no banco os registros do arquivo (não apaga registros que só existem no banco).
